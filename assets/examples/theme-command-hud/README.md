# 指挥舱 HUD（command_hud）v2

**整站骨架**（`siteMode: full`），不是经典侧栏换皮。

| 区域 | 排版 |
|------|------|
| 顶栏 | 航电条：品牌 + **横向导航** + 操作 |
| 左翼 | 遥测柱 / 雷达扫掠 / 波形（装饰面板） |
| 中央 | 旋转环心读数 + **设备密表舞台** |
| 右翼 | 环形表 / 频谱 / 滑条 |
| 登录 | 中央环 + 右侧认证坞 |

设备视图：`table`（密表行，非卡片墙）。

## 安装

打 ZIP（根含 `theme.json` + `templates/`）→ 软件设置 → 主题 → 上传 → 启用。若已装过旧版，请重新上传覆盖。
