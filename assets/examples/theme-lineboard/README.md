# 航线看板（lineboard）

与默认「经典侧栏 + 卡片墙 + 午夜蓝」完全不同的主题（**不内置**，请上传 ZIP 安装）。

| 项 | 默认 | 本主题 |
|----|------|--------|
| 壳层 | classic 侧栏 | **workspace** 左侧图标轨 |
| 设备 | grid 卡片 | **table** 密表行 |
| 登录 | classic 居中卡 | **split** 分栏 |
| 气质 | 深色圆角监控台 | 浅色制图纸 + 锐角墨线 + 信号绿 |

## 启用

将本目录打成 ZIP（根目录含 `theme.json`）→ 软件设置 → 主题 → 上传 → 启用「航线看板」，配色可选「蓝图纸 / 机库夜」。
