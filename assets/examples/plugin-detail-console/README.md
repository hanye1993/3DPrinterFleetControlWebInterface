# 详情控制台（detail_console）

替换设备详情抽屉内的控制区（图二位置）为拓竹式控制台（图一）：

- **顶部摄像头**（多路可切换，快照轮询）
- 喷头 / 热床 / 腔温、风扇、速度、LED
- XY 圆盘 + 热床 Z 行 + 挤出机进退（**点动走宿主 `jog`**，Klipper/拓竹等支持 G-code）
- 暂停 / 恢复 / 取消 / 急停 / 设温
- **AMS + Ext 耗材绑定**（侧视料卷图标、绑定本地料卷、进退料）

风格使用主题 CSS 变量（`--app-*` / `--hud-*`），随当前主题变色。

## 安装

打 ZIP（根含 `plugin.json`）→ 软件设置 → 插件 → 上传 → 启用。（不内置）

**注意：** 宿主需 ≥ 含 `jog` 控制动作的版本；旧版宿主点动会报未知操作。
